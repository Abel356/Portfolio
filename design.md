# Portfolio Design System

## Design Philosophy
- **Modern Minimalism**: Clean, professional aesthetic with purposeful whitespace
- **Technical Excellence**: Design elements that reflect computer science and security expertise
- **Dynamic Interaction**: Smooth animations that enhance user experience without overwhelming
- **Professional Impact**: Sophisticated color palette and typography that commands respect

## Color Palette
- **Primary**: Deep charcoal (#1a1a1a) - professional, technical
- **Secondary**: Soft white (#f8f9fa) - clean, modern
- **Accent**: Electric blue (#0066ff) - tech-forward, trustworthy
- **Accent Alt**: Soft amber (#ffb347) - warm, approachable
- **Success**: Forest green (#22c55e) - achievement, growth
- **Warning**: Sunset orange (#f59e0b) - attention, energy

## Typography
- **Display Font**: "Inter" - modern, technical, highly readable
- **Body Font**: "Source Sans Pro" - professional, clean, excellent for long text
- **Code Font**: "JetBrains Mono" - for technical content and code snippets

## Visual Language
- **Geometric Precision**: Sharp edges, clean lines, structured layouts
- **Subtle Depth**: Soft shadows, gentle gradients, layered elements
- **Technical Motifs**: Circuit patterns, code snippets, network visualizations
- **Professional Photography**: High-quality images for hero and background elements

## Visual Effects
- **Hero Background**: Animated particle system with network connections
- **Text Effects**: Typewriter animation for main heading, color cycling for emphasis
- **Scroll Animations**: Reveal animations triggered at 50% viewport entry
- **Hover States**: 3D transforms, glow effects, color transitions
- **Loading States**: Skeleton screens, progress indicators, smooth transitions

## Layout Principles
- **Grid System**: 12-column responsive grid with consistent spacing
- **Vertical Rhythm**: 24px baseline grid for consistent spacing
- **Content Hierarchy**: Clear visual hierarchy with appropriate contrast ratios
- **Mobile First**: Responsive design starting from 320px viewport

## Component Styling
- **Cards**: Subtle shadows, rounded corners (8px), hover lift effects
- **Buttons**: Solid fills with hover state transformations
- **Forms**: Clean inputs with focus states and validation feedback
- **Navigation**: Fixed header with backdrop blur effect
- **Sections**: Alternating background colors for visual separation
